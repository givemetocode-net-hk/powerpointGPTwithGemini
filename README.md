# PowerPointGPT v1.0.0.0 Alpha

PowerPointGPT is a Python application designed to assist teachers in creating PowerPoint presentations to enhance their teaching experience. This tool leverages the power of AI to generate content that is both informative and engaging for students.

## Features

- **Easy-to-Use Interface**: Built with Tkinter for a user-friendly experience.
- **Content Generation**: Utilizes requests to fetch relevant content and suggestions for presentations.
- **Customizable Presentations**: Tailor the generated content to meet specific educational needs.

## Installation

To set up PowerPointGPT, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/givemetocode-net-hk/powerpointGPTwithGemini.git
   cd powerpointgpt
   ```

2. Install the required packages:
   ```bash
   pip install requests
   ```

3. Run the application:
   ```bash
   python app.py
   ```

## Usage

1. Open the application.
2. Input your topic or keywords related to the presentation.
3. Click the "Generate" button to create content.
4. Customize the generated slides as needed.
